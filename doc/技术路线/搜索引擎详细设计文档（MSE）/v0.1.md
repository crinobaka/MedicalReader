MedicalReader v0.1 搜索引擎详细设计文档（Search Engine TDD）

版本：v0.1 Draft
模块名称：

> MRSE（MedicalReader Search Engine）



定位：

> 面向住院医师工作流的离线医学知识检索引擎。



核心理念：

普通搜索：

> 我知道关键词 → 找内容



MedicalReader：

> 我知道临床概念 → 找知识位置

2. 设计原则

2.1 不允许纯全文搜索作为核心

原因：

医学书：

1000页

全文搜索结果：

几百条。

医生需要：

知识。

不是：

字符串。


---

2.2 搜索必须离线

原因：

医院环境：

无网络

内网限制

隐私要求


所以：

本地Index。


---

2.3 搜索输入英文优先

默认：

英文医学语言。

例如：

推荐：

DKD
HbA1c
metformin
thyroid storm

而不是：

糖尿病肾病

但是：

后台支持中文映射。

6. Index设计

搜索不直接读取MRIF。

导入：

SQLite。


---

6.1 concept_index

医学概念表。

CREATE TABLE concept_index(

id TEXT PRIMARY KEY,

name_en TEXT,

name_zh TEXT,

type TEXT

);


---

例如：

id	en	zh

DKD001	Diabetic Kidney Disease	糖尿病肾病



---

6.2 alias_index

别名表。

CREATE TABLE alias_index(

keyword TEXT,

concept_id TEXT,

weight INTEGER

);

数据：

keyword	weight

DKD	100
Diabetic nephropathy	80
糖肾	50



---

6.3 location_index

定位。

CREATE TABLE location_index(

concept_id TEXT,

book_id TEXT,

page INTEGER,

chapter TEXT

);

15. 性能设计

目标：

100本医学书。

数据量：

假设：

每本：

10000知识节点

总：

100万节点。


---

要求：

搜索：

<300ms


---

方案：

内存缓存

热门：

最近1000查询。


---

SQLite优化

开启：

PRAGMA journal_mode=WAL;

PRAGMA synchronous=NORMAL;


---

建立：

index：

CREATE INDEX idx_keyword

ON alias_index(keyword);
