1. 总体架构设计

1.1 架构目标

MedicalReader 不设计为传统 Flutter App。

核心思想：

> UI只是入口，知识引擎才是核心。



总体结构：

MedicalReader

│
├── Flutter App
│
│   ├── UI Layer
│   ├── State Management
│   └── Platform Bridge
│
│
├── Core Engine (Rust)
│
│   ├── Document Engine
│   ├── Search Engine
│   ├── Index Engine
│   ├── Annotation Engine
│   └── Cache Engine
│
│
├── Storage
│
│   ├── SQLite
│   ├── File System
│   └── Index Package
│
│
└── External

    ├── PDF Engine
    └── OCR Engine

当前TDD结论

第一版技术核心排序：

搜索引擎
    >
医学索引规范
    >
PDF阅读性能
    >
UI

这和普通阅读器完全相反。
