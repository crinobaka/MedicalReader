# MedicalReader 用户与 DIY 指南

> 目标很简单：**不用先学软件，先把书打开。**
>
> 如果你不想折腾配置，全部保持默认即可；如果你喜欢自己改，下面每一步都尽量只需要“看懂、照抄、改一个值”。

## 1. 第一次使用

1. 打开 **书库**。
2. 点击导入 PDF。
3. 导入完成后，回到书库即可看到书。
4. 点击书籍进入阅读器。
5. 阅读器会自动恢复上次阅读位置。
6. 新增文件后，重新打开软件也会自动扫描书库，不需要再手动点一次刷新。

### 手机上文件放在哪里？

Android 如果使用外部存储，请优先选择系统文件选择器能够长期访问的目录，并让系统授予读写权限。不要手工把书移动到一个应用已经失去授权的目录里。

## 2. 阅读器怎么操作

### 手机

- **左右快速滑动**：上一页 / 下一页。
- **单指拖动**：移动当前页面。
- **双指操作**：缩放页面。
- **点击工具栏按钮**：搜索、目录、书签、笔记等。
- 工具太多时进入“更多”，不要在屏幕上硬塞一排按钮。

### Windows / 大屏

- 鼠标滚轮：翻页。
- `Ctrl + 滚轮`：缩放。
- `← / PageUp`：上一页。
- `→ / PageDown`：下一页。
- `Home / End`：第一页 / 最后一页。
- `G`：跳到 PDF 页。
- `B`：跳到书籍页。
- `Ctrl + F`：搜索。

## 3. 书签

看到重要页面就点星标：

- `☆` = 没有书签
- `★` = 已收藏

书签跟随书籍保存，重新打开软件不会丢。

## 4. 设置怎么理解

### 阅读器外观

- **Google**：干净、克制，适合长期使用。
- **Apple**：更圆润、更强调留白。
- **GitHub**：更像开发工具，信息密度较高。
- **悬浮式控件**：工具栏浮在内容附近，适合大屏和窄屏。
- **工具栏位置**：推荐“自动”。
- **阅读画布背景**：跟随系统、纸张、暗色或 DIY。

### 显示控件

每个开关都是独立的。你不喜欢某个按钮，就关掉它；不需要底部翻页条，就关掉它。

**不要为了隐藏一个按钮去改 ReaderPage。** 设置本身就是这个接口。

## 5. DIY：最安全的改法

MedicalReader 把用户可改的内容集中到配置对象和模板文件里。原则是：

> **先改配置，最后才改代码。**

### 阅读器 UI

当前阅读器显示配置对应 `ReaderViewOptions`：

```text
themePreset        google / apple / github / custom
floatingControls   true / false
toolbarPosition    auto / top / bottom
canvasBackground   inherit / paper / dark / custom
customCanvasColor  ARGB 整数，例如 0xFFF4F1EA
```

以后新增一个可定制控件，优先增加配置字段，而不是把判断散落在 `ReaderPage` 里。

### 自定义背景色

ARGB 写成一个整数：

```text
0xFFF4F1EA
```

前两位 `FF` 是不透明度，后六位是 RGB。

## 6. 书籍模板

书籍模板解决的是“这本书怎么看”，例如：

- 书名有哪些别名。
- PDF 页码如何映射到书籍页码。
- 搜索结果显示多少上下文。
- 默认使用什么裁剪方式。

用户模板放在应用数据目录，由设置页管理。

推荐先在设置页复制一个内置模板，再改它，而不是从空白 JSON 开始。

## 7. 文字冒险模板生成器

电脑上运行：

```text
dart run tools/reader_template_generator.dart
```

它会像创建角色卡一样逐项询问：

1. 模板 ID
2. 模板名称
3. 描述
4. 书名别名
5. PDF → 书籍页码偏移
6. 默认裁剪模式
7. 搜索上下文前缀

最后生成 `reader_template.json`。

如果你不喜欢交互式问答，也可以把输出文件名直接传进去：

```text
dart run tools/reader_template_generator.dart my_template.json
```

## 8. 目录生成器：最快建立目录

电脑上运行：

```text
dart run tools/directory_generator.dart outline.txt book.json
```

它读取普通文本的缩进，把文本变成 `book.json`。

### 文件格式规范

**一级目录不缩进；每深入一级，增加 2 个空格。**

例如：

```text
第一章 总论 {pdf=1-20,book=1-18}
  第一节 概述 {pdf=1-5,book=1-4}
  第二节 流行病学 {pdf=6-12,book=5-11}
第二章 诊断 {pdf=21-55,book=19-53}
  第一节 实验室检查 {pdf=21-35,book=19-33}
```

规则：

- 空行会被忽略。
- `#` 开头的行会被当作注释。
- 缩进只能使用 2 个空格的倍数。
- `{pdf=1-20}` 表示 PDF 页范围。
- `{book=1-18}` 表示书籍页范围。
- 两者可以同时出现。
- 只有一个数字时，例如 `{pdf=12}`，起止页都按 12 处理。
- 目录名称本身不要写 JSON，也不要写逗号。

## 9. 模板目录建议

如果你在项目外维护自己的模板，可以按下面组织：

```text
templates/
├── books/
│   ├── textbook.json
│   ├── two-column.json
│   └── custom.json
├── notes/
│   ├── markdown.md
│   ├── markdown_html.html
│   ├── image.html
│   └── audio.html
└── ui/
    └── layout.json
```

其中：

- `books/`：书籍匹配、页码映射、搜索上下文、裁剪默认值。
- `notes/`：Markdown、Markdown-HTML、图片和音频内容模板。
- `ui/`：阅读器布局和主题配置。

**不要把用户模板直接改进程序源码。** 程序升级时，用户文件应该继续存在。

## 10. 裁剪模板的思路

裁剪是“页面布局”，不是简单裁掉四条边。

推荐思路：

1. 打开当前 PDF 页。
2. 用矩形或分割线划出自然区域。
3. 小于合理面积的区域自动吸附或拒绝，避免产生碎片。
4. 需要输出的区域才编号。
5. 不需要的区域可以保持未编号。
6. 同一个 PDF 可以保存多套裁剪方案。
7. 方案可以应用到指定页、页段或组合页。

例如：

```text
{[12,15],[30,55]}
```

表示分别对 12–15 页和 30–55 页应用规则。

PDF 页与书籍页必须保持两套坐标，不能混用。

## 11. “看起来不对”时怎么办

### 页面没有内容

先确认 PDF 文件本身可以被系统打开，再重新进入阅读器。不要立刻删除 metadata。

### 书库刚打开没有书

当前版本会在启动 / 恢复时自动刷新。如果仍然没有，先检查 Library 路径和 Android 外部存储授权。

### 手机上按钮跑出屏幕

优先把操作放进“更多”或底部抽屉，不要强行压缩按钮。窄屏应该减少同时显示的控件，而不是缩小到无法点击。

### 自定义模板加载失败

先复制一个内置模板，再只改一个字段。JSON 最常见的错误是少了逗号、引号或大括号。

## 12. 给喜欢折腾的人

如果你要改 UI，建议遵守这四条：

1. **位置有配置入口。**
2. **显示/隐藏有配置入口。**
3. **尺寸和间距尽量使用主题或布局参数。**
4. **平台差异放在布局层，不要在业务代码里到处 `Platform.isAndroid`。**

如果某个控件只有一个地方使用，可以直接改它；如果它是全局行为，就把参数上提到配置层。

最后一条最重要：

> **不要为了“看起来更灵活”制造 100 个开关。默认值必须好用，DIY 是加分项，不应该变成使用软件的入场考试。**
